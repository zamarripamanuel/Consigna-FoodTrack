# Pasos para crear un repositorio desde cero 

Inicializar el repositorio inicialmente 
1. git init 

Preparar archivos para el punto de guardado 

Agregar un punto para incluir todos los archivos en el próximo punto de guardado 

Listar individualmente los archivos si es que queremos omitir alguno 

2. git add .
2. git add nombre_del_archivo.extension 

Generar la versió nueva que incluye los archivos que se han agregados al previo git add 

3. git commit -m "Primer commit, agregando archivos del proyecto" 

Crear la rama principal de nuestro repositorio llamado main 

4. git branch -M main 

Enlazar el repositorio local con nuestra cuenta de Github
